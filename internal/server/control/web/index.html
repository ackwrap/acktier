Bind the owner public key

Choose a trusted computer to act as the network owner. Keep the signing key on that computer and give the center its public trust.json.

  1. STEP 01 Initialize a root key locally

    On the owner computer, run acktier owner init --dir ./data/owner and keep a secure offline backup of signer.json.

  2. STEP 02 Upload and verify the network fingerprint

    Select the public trust.json below and verify its SHA-256 network fingerprint. Keep the private key on the owner computer.

  3. STEP 03 Bind the trust root and enable coordination

    The center accepts join requests after binding. The Web console cannot replace the owner root key.

Select or drop trust.json here Public trust files up to 16 KiB. The browser rejects private key files before upload.
